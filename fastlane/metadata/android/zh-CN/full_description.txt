Keepout 是一款无需 root 的 Android 防火墙、加密 DNS 和 VPN 应用。决定哪些应用可以联网，在广告和跟踪器连接之前就将其拦下，并查看手机发出的每一次连接。

防火墙
• 一键拦截任意应用的 Wi-Fi、移动数据或两者。
• 隔离应用、让应用绕过规则，或将其排除在隧道之外。
• 通用规则：在后台、屏幕关闭时或安装新应用时拦截应用。
• 针对单个应用或所有应用的 IP、端口和域名规则。

加密 DNS
• Rethink DNS，搭配针对广告、跟踪器和恶意软件的本地屏蔽名单。
• 也可以通过 DNS-over-HTTPS、DNS-over-TLS、DNSCrypt 或 ODoH 使用自选解析服务。
• DNS 响应在本地校验，同时还能绕过基于 DNS 的审查。

查看应用在做什么
• 网络和 DNS 日志：哪个应用、哪台服务器、哪个国家，放行还是拦截。
• 过去一小时、一天或一周的统计：热门应用、被拦截的应用、国家、网络和域名。

VPN 与代理
• 通过 WireGuard、SOCKS5 或 HTTP 代理转发应用流量，支持按应用分流。
• 借助 Orbot 一键连接 Tor。

隐私至上
过滤通过 Android 的 VPN 服务在你的设备上完成。日志只保存在手机上，可以随时关闭，而且没有广告。

Keepout 是 Celzero 出品的 Rethink DNS + Firewall 的开源分支，采用 Material 3 Expressive 重新设计，基于 Apache 2.0 许可证发布。

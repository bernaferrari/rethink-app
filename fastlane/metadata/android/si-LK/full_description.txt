Keepout යනු Android සඳහා root අවශ්‍ය නොවන firewall, සංකේතිත DNS සහ VPN එකකි. අන්තර්ජාලයට යා හැක්කේ කුමන යෙදුම්ද යන්න තීරණය කරන්න, දැන්වීම් සහ trackers සම්බන්ධ වීමට පෙරම නවත්වන්න, ඔබේ දුරකථනය කරන සෑම සම්බන්ධතාවක්ම බලන්න.

FIREWALL
• ඕනෑම යෙදුමක් Wi-Fi, ජංගම දත්ත හෝ දෙකෙහිම එක් තට්ටුවකින් අවහිර කරන්න.
• යෙදුමක් හුදකලා කරන්න, නීති bypass කිරීමට ඉඩ දෙන්න, නැතහොත් tunnel එකෙන් බැහැර කරන්න.
• විශ්ව නීති: පසුබිමේදී, තිරය අක්‍රිය විට හෝ නව යෙදුමක් ස්ථාපනය කළ විට යෙදුම් අවහිර කරන්න.
• එක් යෙදුමකට හෝ සියලු යෙදුම්වලට IP, port සහ වසම් නීති.

සංකේතිත DNS
• දැන්වීම්, trackers සහ malware සඳහා උපාංගයේම ඇති අවහිර ලැයිස්තු සමඟ Rethink DNS.
• නැතහොත් DNS-over-HTTPS, DNS-over-TLS, DNSCrypt හෝ ODoH හරහා ඔබේම resolver එකක් තෝරන්න.
• DNS පිළිතුරු උපාංගයේදීම පරීක්ෂා කෙරෙන නිසා, DNS මත පදනම් වූ වාරණයද මඟ හැරේ.

ඔබේ යෙදුම් කරන දේ බලන්න
• ජාල සහ DNS ලොග: කුමන යෙදුම, කුමන server එක, කුමන රට, ඉඩ දුන්නාද අවහිර කළාද.
• පසුගිය පැය, දවස හෝ සතිය සඳහා සංඛ්‍යාලේඛන: ඉහළම යෙදුම්, අවහිර කළ යෙදුම්, රටවල්, ජාල සහ වසම්.

VPN සහ PROXIES
• යෙදුම් WireGuard, SOCKS5 හෝ HTTP proxies හරහා යවන්න, එක් එක් යෙදුමට split tunneling සමඟ.
• Orbot හරහා එක් තට්ටුවකින් Tor.

නිර්මාණයෙන්ම පෞද්ගලිකයි
පෙරීම Android හි VPN සේවාව හරහා ඔබේ උපාංගයේම සිදු වේ. ලොග දුරකථනයේම රැඳේ, ඔබට ඒවා අක්‍රිය කළ හැකිය, දැන්වීම් නැත.

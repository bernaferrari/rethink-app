Keepout adalah firewall tanpa root, DNS terenkripsi, dan VPN untuk Android. Tentukan aplikasi mana yang boleh mengakses internet, hentikan iklan dan pelacak sebelum terhubung, dan lihat setiap koneksi yang dibuat ponsel Anda.

FIREWALL
• Blokir aplikasi apa pun di Wi-Fi, data seluler, atau keduanya, dengan sekali ketuk.
• Isolasi aplikasi, biarkan melewati aturan, atau kecualikan dari tunnel.
• Aturan universal: blokir aplikasi di latar belakang, saat layar mati, atau saat aplikasi baru diinstal.
• Aturan IP, port, dan domain untuk satu aplikasi atau semua aplikasi.

DNS TERENKRIPSI
• Rethink DNS dengan daftar blokir di perangkat untuk iklan, pelacak, dan malware.
• Atau pilih resolver sendiri melalui DNS-over-HTTPS, DNS-over-TLS, DNSCrypt, atau ODoH.
• Jawaban DNS diperiksa secara lokal, sehingga juga menembus sensor berbasis DNS.

LIHAT APA YANG DILAKUKAN APLIKASI ANDA
• Log jaringan dan DNS: aplikasi mana, server mana, negara mana, diizinkan atau diblokir.
• Statistik untuk jam, hari, atau minggu terakhir: aplikasi teratas, aplikasi yang diblokir, negara, jaringan, dan domain.

VPN DAN PROXY
• Arahkan aplikasi melalui proxy WireGuard, SOCKS5, atau HTTP, dengan split tunneling per aplikasi.
• Tor sekali ketuk melalui Orbot.

PRIVAT SEJAK AWAL
Pemfilteran berjalan di perangkat Anda melalui layanan VPN Android. Log tetap di ponsel, Anda bisa menonaktifkannya, dan tidak ada iklan.

Keepout adalah fork open source dari Rethink DNS + Firewall oleh Celzero, didesain ulang dengan Material 3 Expressive. Berlisensi Apache 2.0.

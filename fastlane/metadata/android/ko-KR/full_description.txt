Keepout는 루팅이 필요 없는 Android용 방화벽, 암호화 DNS, VPN입니다. 어떤 앱이 인터넷에 접속할지 정하고, 광고와 추적기를 연결 전에 막고, 휴대전화의 모든 연결을 확인하세요.

방화벽
• 탭 한 번으로 Wi-Fi, 모바일 데이터 또는 둘 다에서 앱을 차단합니다.
• 앱을 격리하거나, 규칙을 우회하게 하거나, 터널에서 제외할 수 있습니다.
• 범용 규칙: 백그라운드 상태, 화면이 꺼졌을 때, 새 앱이 설치되었을 때 앱을 차단합니다.
• 앱 하나 또는 모든 앱에 적용되는 IP, 포트, 도메인 규칙.

암호화 DNS
• 광고, 추적기, 악성코드를 막는 기기 내 차단 목록을 갖춘 Rethink DNS.
• 또는 DNS-over-HTTPS, DNS-over-TLS, DNSCrypt, ODoH로 원하는 리졸버를 선택하세요.
• DNS 응답을 기기에서 직접 검증하므로 DNS 기반 검열도 우회할 수 있습니다.

앱이 하는 일 확인
• 네트워크 및 DNS 로그: 어떤 앱이, 어떤 서버로, 어느 국가로, 허용 또는 차단.
• 최근 1시간, 1일, 1주 통계: 주요 앱, 차단된 앱, 국가, 네트워크, 도메인.

VPN 및 프록시
• 앱별 분할 터널링으로 WireGuard, SOCKS5, HTTP 프록시를 통해 앱을 연결합니다.
• Orbot을 통해 탭 한 번으로 Tor에 연결.

설계부터 개인정보 보호
필터링은 Android의 VPN 서비스를 통해 기기에서 실행됩니다. 로그는 휴대전화에만 저장되고 끌 수도 있으며, 광고도 없습니다.

Keepout는 Celzero의 Rethink DNS + Firewall을 Material 3 Expressive로 새롭게 디자인한 오픈소스 포크입니다. Apache 2.0 라이선스로 배포됩니다.
